# ☄ Cosmic Palette!

##  [Live Demo](https://cosmic-palette.navarroweb.net/)
Try out the app for yourself! :)

## App's description & features

Cosmic Palette is a simple web app that fetches NASA's Picture of the Day (APOD) free API and generates a 5, 8 or 10 color palette. You can generally choose which format you'd like to copy the colors in: Tailwind CSS, HEX, or RGB. Or choose individually. You can also export all colors in Tailwind CSS, CSS variables, and JSON formats.

NASA's APOD: The app gets the picture, title, image credit and copyright information, as well as the image's description. I designed cosmic palette to get images from the last 12 days so you can pick difference choices. 

I used the Color Thief library to extract colors from each image and Lucide React icons. Connecting to NASA's free APIs is a great opportunity to take my coding skills further, and I'm looking forward to learning more and more!

## Tech Stack
- **Frontend:** React (powered by Vite) with TypeScript, color Thief (generating color palette) and lucide-react (for icons)
- **Styling:** Tailwind CSS

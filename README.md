# 🌌 Cosmic Palette

**Turn the wonders of the universe into beautiful color palettes.**

Cosmic Palette is a web application that uses NASA's Astronomy Picture of the Day (APOD) to generate color palettes inspired by the cosmos. Explore stunning astronomical images, discover their colors, and export palettes ready to use in your next design or development project.

🚀 **[Explore the live demo](https://cosmic-palette.navarroweb.net/)**

## ✨ Features

- **NASA Astronomy Pictures:** Explore the latest Astronomy Picture of the Day, including its title, date, image credits, copyright information, and full description.
- **Custom Color Palettes:** Extract color palettes directly from astronomical images with your choice of 5, 8, or 10 colors.
- **Historical Image Exploration:** Discover previous astronomy pictures and generate palettes from images published in the past.
- **Multiple Color Formats:** Copy individual colors as HEX or RGB values.
- **Tailwind CSS Integration:** Copy generated color styling in Tailwind CSS format.
- **Bulk Palette Export:** Export your entire palette in multiple formats:
  - Tailwind CSS
  - CSS custom properties (variables)
  - JSON
- **Responsive Interface:** Explore the universe and its colors through a clean, intuitive web experience.

## 🪐 Data Source

Cosmic Palette retrieves astronomical images and their associated information from NASA's Astronomy Picture of the Day resources.

- **APOD website:** https://science.nasa.gov/apod/

The application displays the latest available image by default and allows users to explore previous images when supported by the available data.

## 🎨 How It Works

1. **Discover:** Load the latest astronomical image or explore a previous one.
2. **Explore:** Read the image's title, publication date, credits, copyright information, and description.
3. **Extract:** Generate a palette containing 5, 8, or 10 colors from the selected image.
4. **Customize your workflow:** Copy individual HEX or RGB values or retrieve the generated Tailwind CSS styling.
5. **Export:** Download or copy the complete palette in Tailwind CSS, CSS variables, or JSON format.

## 💡 Use Cases

Cosmic Palette can help developers and designers:

- Create color schemes inspired by nebulae, galaxies, planets, and other celestial objects.
- Generate palettes for websites, applications, and UI prototypes.
- Quickly obtain HEX and RGB values for design systems.
- Integrate image-inspired colors into Tailwind CSS projects.
- Export reusable color tokens for different development workflows.

# ☄ Cosmic Palette!

A simple web app that fetches NASA's APOD API and generates a color paletette. Which you can export to tailwind, css and json format!

## 🚀 [Live Demo](https://cosmic-palette.navarroweb.net/)

You can try out the application! No credentials needed!

## App's description

Cosmic Palette is a simple web app that fetches NASA's Picture of the Day (APOD) and generates a 5-, 8-, or 10-color palette. You can generally choose which format you'd like to copy the colors in: Tailwind CSS, HEX, or RGB. Or choose individually—it's all up to you!

You can also export all colors in Tailwind CSS, CSS variables, and JSON formats.

APOD: You get the picture, title, image credit and copyright information, as well as the image's description.

You can see all the images generated within the last 12 days! Amazing, right? I believe this is a great opportunity to learn about space, see fun pictures, and extract fun colors if you're looking for design ideas.

This project helped me improve my React, Vite, and TypeScript skills. I used the Color Thief library to extract colors from each image and Lucide React icons. Connecting to NASA's free APIs is a great opportunity to take my coding skills further, and I'm looking forward to learning more and more!

## 🛠️ Technologies Used

This project is built with a modern, fast, and scalable stack:

- **Frontend:** React (powered by Vite) with TypeScript, color Thief (generating color palette) and lucide-react (for icons)
- **Styling:** Tailwind CSS
